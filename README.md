# Расходы — личные финансы (Android, офлайн)

Нативное Android-приложение для учёта расходов и доходов, анализа и поиска
«утечек» бюджета. Работает **полностью офлайн**, без аккаунтов и серверов: все
данные хранятся только на устройстве. Язык — русский, валюта — рубль (₽).

Логика повторяет проверенный Excel-шаблон (листы «Учет расходов», «Учет доходов»,
«Справочники», дашборд и графики) и переносит его в удобное мобильное приложение.

> ⚠️ Это инструмент учёта и анализа, а не финансовый или инвестиционный совет.

---

## Возможности

- **Дашборд** с выбором месяца: KPI (Доход, Расход, Чистыми, **Норма сбережений**,
  средний чек, в накопления), график «Доход и расход» по месяцам, топ категорий и
  блок **«Детектор утечек»**.
- **Детектор утечек** — честно подсвечивает категории, чья доля в расходах выше
  порога (по умолчанию 15%) **или** выросшие более чем на +30% к среднему за 3
  предыдущих месяца. Отдельно отмечаются «необязательные траты». Пороги настраиваются.
- **Операции (журнал)** — список с поиском, фильтрами по типу и месяцу, итогами;
  редактирование по тапу, удаление свайпом с подтверждением. Денежные значения —
  табличными цифрами (tnum).
- **Быстрое добавление** операции (FAB «+» с любого экрана): тип, сумма, дата,
  категория/подкатегория из справочника, описание, комментарий.
- **Категории (справочник)** — полностью редактируемые: создание/переименование/
  удаление, цвет, флаг «необязательная трата», подкатегории. Засеяны реальными
  категориями из шаблона.
- **Аналитика** — расходы по категориям и подкатегориям, доходы по источникам,
  динамика по месяцам. Период: месяц / год / всё время.
- **План-факт** — план/факт/разница по категориям за месяц с подсветкой перерасхода.
- **Фонды и цели** — «Подушка безопасности», «Отпуск» и т.п. с прогресс-баром и
  историей пополнений/списаний.
- **Калькулятор распределения дохода** — доли (по умолчанию 75/15/10, есть пресет
  50/30/20), точная разбивка в ₽ без потери копеек.
- **Импорт/экспорт** через Storage Access Framework (без широких разрешений):
  - **Выгрузка в Google Таблицы одной кнопкой** (см. ниже);
  - экспорт **Excel (.xlsx)**, **CSV** (расходы/доходы), **полный бэкап (JSON)**;
  - импорт **CSV** (листы шаблона) и восстановление из **JSON** — с предпросмотром.
- **Настройки** — тёмная/светлая тема (по умолчанию тёмная), пороги детектора
  утечек, тумблер демо-данных (по умолчанию выключен).

## Выгрузка в Google Таблицы одной кнопкой

Экран **Ещё → Импорт и экспорт → «Выгрузить в Google Таблицы»**:

1. Приложение формирует книгу `.xlsx` с листами «Учет расходов» и «Учет доходов».
2. Открывается системное «Поделиться» — выберите **Google Таблицы** или **Google
   Диск** (если установлены, откроются сразу).
3. Google Таблицы импортируют файл как **полноценную таблицу**.

**Почему так, а не через Google Sheets API.** Этот способ:
- не требует разрешения на интернет внутри приложения (данные не покидают
  устройство «втихую» — вы сами выбираете, куда отправить файл);
- не требует входа в аккаунт Google, OAuth и проекта в Google Cloud Console;
- работает на любом телефоне «из коробки».

Прямая запись в конкретную таблицу через Google Sheets API возможна как будущее
расширение, но требует разрешения `INTERNET`, Google Sign-In и настройки OAuth
client с привязкой к подписи приложения — это противоречит принципу «офлайн» и
усложняет установку, поэтому по умолчанию используется выгрузка через «Поделиться».

## Сборка и установка

### Требования
- **Android Studio** (Ladybug 2024.2 или новее). JDK 17 идёт в комплекте со студией.
- Доступ в интернет при первой сборке (Gradle скачает зависимости с
  `maven.google.com` и Maven Central).
- Телефон с **Android 8.0 (API 26)** или новее.

### Открыть и собрать
1. Установите Android Studio (один раз).
2. **File → Open** и выберите папку проекта. Дайте студии скачать Gradle 8.11.1,
   Android SDK и зависимости (может занять несколько минут).
3. Сборка debug-APK из терминала:
   ```bash
   ./gradlew assembleDebug
   ```
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Запуск на телефоне
- **Через Android Studio:** включите на телефоне «Отладку по USB», подключите
  кабелем, нажмите **Run ▶**.
- **Установка APK вручную:** перенесите `app-debug.apk` на телефон и откройте его;
  разрешите «Установка из неизвестных источников» для проводника/браузера.

## Тесты

Вся денежная математика и аналитика вынесены в чистый Kotlin-модуль **`:core`**
(без Android-зависимостей) и покрыты JUnit-тестами:

```bash
./gradlew :core:test
```

Покрыто (30 тестов): парсинг/форматирование денег и устойчивость к float-артефактам
(`63372.90000000001` → копейки без мусора), округление HALF_UP, KPI и норма
сбережений при нулевом доходе («—»), доли, рост MoM, **детектор утечек** (по доле и
по росту), **план-факт**, **калькулятор распределения** (без потери копеек), CSV
(кавычки/разделители/переводы строк) и **маппинг колонок Excel-шаблона** при импорте.

Дополнительно:
- `./gradlew :app:test` — генератор `.xlsx`;
- `./gradlew :app:connectedDebugAndroidTest` — тест Room DAO на in-memory базе
  (нужен подключённый телефон/эмулятор).

## Импорт данных из Excel

Самый надёжный путь миграции:
1. В Excel/Google Таблицах откройте лист **«Учет расходов»** (или «Учет доходов»).
2. Сохраните его как **CSV** (Файл → Сохранить как → CSV).
3. В приложении: **Ещё → Импорт и экспорт → Выбрать файл** → укажите CSV.
4. Проверьте **предпросмотр** (сколько строк распознано, сколько пропущено и почему)
   и подтвердите.

Распознаются столбцы шаблона: `Месяц · Год · Дата · Категория · Подкатегория ·
Подробное описание · Стоимость · Комментарий` (расходы) и `… · От кого пришло ·
Категория · … · Приход · Вложено в бюджет · Остаток на накопления · …` (доходы).
Строки без даты и суммы пропускаются и показываются в предпросмотре.

Прямой импорт `.xlsx` намеренно не делался: Apache POI тяжёл и тянет multidex/размер
APK. Экспорт в `.xlsx` при этом есть (лёгкий собственный генератор без POI).

## Архитектура

- **Kotlin + Jetpack Compose**, только Compose (без XML-вёрстки экранов), **Material 3**.
- **Dynamic Color (Material You) выключен** — своя графитово-стальная палитра.
- **Room (SQLite)** — локальное хранилище; **DataStore** — настройки.
- **ViewModel + Kotlin Flow/StateFlow**, repository-паттерн, однонаправленный поток данных.
- **Edge-to-edge**, поддержка системной тёмной темы, табличные цифры (`tnum`).
- Модули: **`:core`** (чистый Kotlin: деньги, аналитика, CSV, импорт-маппинг) и
  **`:app`** (Android UI и данные).

### Принятые решения и допущения
- **Ручной DI** вместо Hilt — для приложения такого размера чище и надёжнее в сборке
  (меньше процессоров аннотаций).
- **Графики — собственные на Compose Canvas** (столбчатые, кольцевые, полосы), а не
  сторонняя библиотека: исключает риск несовпадения версий/API. Vico можно
  подключить позже.
- **Деньги — целые копейки (`Long`)**; парсинг и округление (HALF_UP) — в одном месте
  `com.rashodi.core.money.Money` через `BigDecimal`. Никакой денежной арифметики в
  `Double`/`Float`.
- **Шрифт** — системный гротеск (Roboto) с табличными цифрами. Чтобы использовать
  Inter/Manrope, положите `.ttf` в `app/src/main/res/font` и замените `AppFont`
  в `ui/theme/Type.kt`.
- **Нет разрешения `INTERNET`** и сетевых вызовов: данные не покидают устройство.
- **Демо-данные** выключены по умолчанию и помечены как демо (`isDemo`); реальный
  старт — пустое состояние с засеянными категориями.
- При нулевом знаменателе производные метрики не выдумываются — показывается «—».

  analytics/              # KPI, детектор утечек, план-факт, распределение

app/                      # Android-приложение (Compose)
